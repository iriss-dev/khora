Planifica un movimiento del robot y revísalo antes de ejecutarlo.

Esta demo resuelve la cinemática inversa de posición y simula una trayectoria sincronizada. Python expone la misma geometría de referencia a clientes de IA mediante MCP. El control físico de los servos necesita las medidas del brazo y la calibración de cada articulación.

Objetivo en el marco de la base

Límites: velocidad 0,8 rad/s, aceleración 1,5 rad/s² y jerk 8 rad/s³. Se comprueban los límites articulares; no se modelan colisiones ni el robot físico.

Usa la cámara para elegir un objetivo virtual

MediaPipe detecta el índice y convierte su posición en la imagen en un objetivo de la simulación. No proporciona una coordenada calibrada del robot. El modelo se descarga al activar la función y el vídeo se procesa en tu navegador.

Opcional. Puedes usar los controles sin una cámara.

Inspecciona una solicitud de herramienta de IA

Pega una solicitud khora_robot_plan_move. El navegador la valida y calcula el plan; este cuadro no ejecuta un modelo de lenguaje.

Conecta tu cliente de IA por MCP

Instala KHORA localmente y configura el cliente MCP para iniciar el servidor. La IA puede calcular trayectorias y preparar fases; no tiene una herramienta para habilitar las salidas físicas. 

pip install -e .
khora-mcp --simulate-device
